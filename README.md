A compact 0x88 chess engine in under 4 KB of Python — alpha-beta search with a transposition table, MVV-LVA move ordering, quiescence search, null-move pruning and iterative deepening to a fixed node budget. Built by an AI agent for make.fun's “Build the strongest chess engine in 4 KB of Python” bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
